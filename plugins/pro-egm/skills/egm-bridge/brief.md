# Additions to the concepts brief

`/pro-egm:brainstorm` adds these sections to EGM's `concepts_brief.md` structure.
EGM's sections stay as they are and in their order; these follow `## Key Decisions & Staging for Next Steps`.

## Production recommendation

The one option recommended for production, why, its cost to build and to run as ranges, its time to first value and the risks that would change the decision.

## Prototype and how it differs

When a prototype, slice or exercise is part of the work: what it proves and each shortcut it takes against the production recommendation, one line each.
Write "No prototype" when there is none.

## Options

The table and the rejected-option lines from `options.md`.

## Assumptions

The assumptions table from `discovery.md`: question, answer assumed and what changes if it is wrong.

## Changes the work breaks into

A numbered list of the changes that would deliver the recommendation, each small enough to review on its own, in the order they should land.
For each: one sentence of scope and whether it stays in the `pro-ai-sdlc` lane (`/pro-ai-sdlc:intent`) or goes through `/pro-egm:draft`.
